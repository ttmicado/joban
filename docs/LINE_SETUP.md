# LINE通知（公式アカウント連携）のセットアップ

LINE 公式アカウント（Messaging API）をチームの LINE グループに招待すると、アプリの出来事
（新しい予定・変更・中止・日程調整・試合結果・お知らせ・新メンバー）が自動でグループに流れ、
前日リマインド・起床チェック・出欠締切・成績入力のリマインドも自動で届くようになります。
グループで「次の予定」「出欠」「ランキング」「ヘルプ」と送ると返事もします。

この機能は任意です。下記の環境変数が無いときは何もしません（エラーにもなりません）。

## 1. Messaging API チャネルを作る

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログイン
2. LIFF アプリと**同じプロバイダー**を開き、「新規チャネル作成」→「Messaging API」を選ぶ
   - チャネル名がそのまま公式アカウントの名前になります（例: 常磐ナイン 連絡係）
3. 作成したチャネルの「チャネル基本設定」で **チャネルシークレット** を確認
4. 「Messaging API設定」の一番下で **チャネルアクセストークン（長期）** を発行

## 2. シークレットを Workers に登録する

```bash
npx wrangler secret put LINE_MESSAGING_TOKEN    # チャネルアクセストークン（長期）
npx wrangler secret put LINE_MESSAGING_SECRET   # チャネルシークレット
```

- 値はコードや wrangler.jsonc に書かないでください（API の応答やログにも出しません）
- 通知の「アプリで開く」ボタンには `LIFF_ID`（wrangler.jsonc の vars）を使います。未設定だとボタンが付きません
- ローカルで試すときは `.dev.vars` に書くか、`npx wrangler dev --var LINE_MESSAGING_SECRET:xxx` で渡します

## 3. Webhook URL を設定する

「Messaging API設定」の **Webhook設定** で:

1. Webhook URL に `https://<アプリのドメイン>/api/line/webhook` を入力
   （アプリの「その他 → LINE通知」画面にコピーできる URL が表示されます）
2. 「検証」を押して「成功」と出ることを確認
3. **Webhookの利用** をオン

署名（`x-line-signature`）はチャネルシークレットで検証し、一致しないリクエストは 401 で拒否します。

## 4. 応答メッセージ・あいさつメッセージをオフにする

[LINE Official Account Manager](https://manager.line.biz/) → 対象アカウント → 設定 → **応答設定** で

- 応答メッセージ: **オフ**
- あいさつメッセージ: **オフ**
- Webhook: **オン**

（オンのままだと、グループの発言に自動応答が返ってしまいます）

## 5. グループトークへの参加を許可する

「Messaging API設定」または Official Account Manager の **アカウント設定** で
「**グループトーク・複数人トークへの参加を許可する**」をオンにします。

## 6. 公式アカウントをチームのグループに招待する

1. 公式アカウントを友だち追加（Messaging API設定の QR コード）
2. チームの LINE グループの「メンバー → 招待」から公式アカウントを招待
3. 公式アカウントが「招待ありがとうございます」とあいさつすれば OK

招待されたグループはアプリに自動で記録されます（グループ名も取得します）。

## 7. アプリで通知先を選ぶ

1. 管理者でアプリを開き、「その他 → LINE通知」へ
2. チェックリストがすべて ✓ になっていることを確認
3. 「通知先グループ」から、チームのグループを選ぶ
4. 届けたい通知の種類をスイッチでオン/オフ（お知らせは「オフ / 重要のみ / すべて」）
5. 「テスト送信」を押して、グループにメッセージが届けば完了です 🎉

グループが一覧に出ないときは、グループで「ヘルプ」と送ってから「更新」を押してください。

## 届く通知とタイミング

| 種類 | タイミング |
| --- | --- |
| 新しい予定 | 予定が追加されたとき |
| 予定の変更・中止 | 日付・集合時間・集合場所・開始時間・球場が変わったとき／中止になったとき |
| 日程調整の開始・決定 | 候補日の募集開始／日程の決定 |
| 試合結果 | 試合結果が確定したとき（スコアボード・MVP・活躍した選手） |
| お知らせ | 重要のみ（既定）またはすべて |
| 新メンバー | アプリに新しいメンバーが参加したとき |
| 前日リマインド | 予定の前日 20:00（集合時間・球場・持ち物・出席人数・未回答者） |
| 当日の起床チェック | 集合の 90 分前（出席予定なのに起床報告が無い人の名前） |
| 出欠締切リマインド | 出欠締切日の前日 20:00（未回答者の名前） |
| 成績入力リマインド | 試合の翌日 20:00（成績が未入力＝打席 0 の出場者の名前） |

リマインドは 15 分ごとの cron で判定し、同じ内容は二度送りません。

## グループで使えるコマンド

通知先に選んだグループでだけ返事をします（他のグループにはチームの情報を出しません）。

- `次の予定` … 次の予定の日時・集合・球場・出欠人数
- `出欠` … 次の予定の出欠状況と未回答者
- `ランキング` … 今季の打撃ランキング（打率・本塁打・打点・安打）
- `ヘルプ` … コマンド一覧とアプリのリンク

## 困ったとき

- **テスト送信が失敗する**: 「最近の送信」に失敗理由が出ます。`HTTP 401` はトークンの誤り、
  `HTTP 400`/`403` は公式アカウントがグループにいない（退出した）ことが多いです
- **Webhook の検証が失敗する**: `LINE_MESSAGING_SECRET` がチャネルシークレットと一致しているか確認
- **通知を止めたい**: 種類ごとのスイッチをオフにします（グループから公式アカウントを退出させても止まります）
