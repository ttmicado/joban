# 宿泊券ガラポン（LINEミニアプリ）

LINEグループのメンバーがミニアプリを開いて **LINEアカウントでエントリー → ガラポンを回す** と、
金の玉が出た人が宿泊券に当選する抽選アプリです。

- 玉の数 = 参加人数（初期値 **19**）、金の玉 = 当選数（初期値 **2**）
- 回すたびに箱から玉を1個ずつ取り出す方式（非復元抽出）。
  **何番目に回しても当選確率は 2/19 で同じ**で、全員が回し終わると当選者は**必ず2人**になります
- 抽選はサーバー側（Cloudflare Durable Object）で1件ずつ処理するので、同時に回されても金の玉が3個出ることはありません
- 1人1回だけ。LINEのユーザーIDで本人を識別し、アプリを開き直しても結果は変わりません

## 演出

- 提灯が揺れる夜の縁日風の画面。宿泊券チケットが光り、金の玉の残り数が見える
- エントリーするとハンコが「ドン！」と押された整理券が出る
- ガラポンは **ハンドルを指でぐるぐる回して** 操作（1.5回転で玉が出る）。玉がぶつかる「カラカラ」音と振動つき
  - うまく回せない人向けの「自動で回す」ボタンもあり
- 規定回転に達するとドラムロール → ドラムが減速して出口が下に → ガタガタ揺れて玉がコロン
- 金の玉なら画面いっぱいにズーム → 白フラッシュ → 「大当たり!!」・鐘のカランカラン・ファンファーレ・紙吹雪と金貨
- 白い玉なら「ざんねん、ハズレ…」と、残りの金の玉の数を表示
- 「みんなの結果」で全員の状況をリアルタイムで確認。誰かが当てるとトーストで通知
- 当選者は「グループに結果を報告する」でLINEグループにカードを送れる（shareTargetPicker）

効果音はすべて Web Audio で合成しているので、音声ファイルは不要です。

## 構成

| パス | 内容 |
| --- | --- |
| `src/worker.js` | Cloudflare Worker（API・LINE認証）と抽選状態を持つ Durable Object |
| `src/lottery.js` | 抽選ロジック（純粋関数・テストあり） |
| `public/` | ミニアプリ本体（HTML/CSS/JS、ビルド不要） |
| `public/admin.html` | 管理画面（設定変更・結果確認・リセット） |

## セットアップ

### 1. LINE Developers でミニアプリを作る

1. [LINE Developers コンソール](https://developers.line.biz/console/) でプロバイダーを選び、
   **LINEミニアプリ** チャネルを作成（身内で使うだけなら未認証のままでOK）
2. 「ウェブアプリ設定」で
   - エンドポイントURL：あとでデプロイするURL（例 `https://joban-garapon.<あなた>.workers.dev`）
   - Scope：`openid`、`profile` をオン
   - **shareTargetPicker** をオン（当選報告ボタン用）
3. 控えておくもの
   - **LIFF ID**（例 `2001234567-AbCdEfGh`）
   - **チャネルID**（チャネル基本設定にある数字）

> 既存の LINEログイン チャネルの LIFF アプリでも動きます。その場合は同じチャネルのチャネルIDを使ってください。

### 2. デプロイ（Cloudflare Workers・無料枠で動作）

```bash
npm install
npx wrangler login
```

`wrangler.jsonc` の `vars` に控えた値を入れます。

```jsonc
"vars": {
  "LIFF_ID": "2001234567-AbCdEfGh",
  "LINE_CHANNEL_ID": "2001234567",
  "ALLOW_MOCK": "false"
}
```

```bash
npx wrangler secret put ADMIN_KEY   # 管理画面用のパスワードを入力
npm run deploy
```

表示されたURLを、LINE Developers のエンドポイントURLに設定します。

### 3. LINEグループに送る

`https://miniapp.line.me/<LIFF ID>`（または `https://liff.line.me/<LIFF ID>`）を19人のLINEグループに投稿してください。
タップするとLINE内でミニアプリが開きます。

### 4. 管理画面

`https://<デプロイ先>/admin.html` を開き、`ADMIN_KEY` を入力すると

- 玉の数（参加人数）・当選数・景品名の変更
- エントリー受付の締め切り
- 参加者と結果の一覧
- 抽選結果のリセット（テスト後に本番を始めるとき）

ができます。

> **参加人数が19人より少なくなりそうな場合**：玉が余って金の玉が残ることがあります。
> 全員のエントリーが済んだ時点で、管理画面で「玉の数」をエントリー人数に合わせてから回してもらうと、
> 必ず2人当選になります（誰かが回し始めた後に変えると確率が変わるので、変更は回し始める前に）。

## ローカルで試す

LINEなしでも、モックログインで画面の動きを確認できます。

```bash
printf 'ALLOW_MOCK=true\nADMIN_KEY=test-admin\n' > .dev.vars
npm run dev
```

- `http://localhost:8787/?mock=1&name=田代` … 「田代」としてエントリー（`mock` の値を変えると別人になります）
- `http://localhost:8787/admin.html` … 管理キー `test-admin`

テスト：

```bash
npm test
```

（19人全員が回すと当選がちょうど2人になること、回す順番で当選確率が変わらないことなどを確認しています）
